# Hawaiʻi RHTP dashboard demo

A temporary public review copy for feedback. This is an illustrative interface, not an official state dashboard.

Red text and pink shading mark fictional progress, payments and plans. Recorded award facts, application targets and budget estimates are sourced within the dashboard.

The site uses a standalone HTML file and has no external scripts or data collection.

This review site remains available until it is unpublished. The HTML requests that search engines not index it; this is not access control.
